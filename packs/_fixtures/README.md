# Fixture packs (tests only)

Deliberately unlike the launch packs, so core tests can prove nothing is hard-coded. Never listed in a cell's `ALLOWED_PACKS`.
A test that passes under `gb-eaw / clin-neg-breach / general-practice` must also pass under `zz-test / zz-case / zz-specialty`,
with the words, rules and dates changing as these files say.
