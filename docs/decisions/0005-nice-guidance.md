# 0005 NICE guidance versions

Date: 2026-10-15 · Status: accepted

**Decision.** Keep a hand-curated `guideline_versions` table (guideline, version, in force from/to, link), starting with the 20–30 guidelines behind most GP claims. Screens show the version label and a link; the expert reads the guidance. No NICE text goes to Claude until NICE approves AI use.

**Why.** UK reuse is free under the NICE UK Open Content Licence, but AI use is excluded and needs separate approval. The NICE API has current versions only.

**Action.** Apply for AI permission via the NICE syndication API application form or reuseofcontent@nice.org.uk.
