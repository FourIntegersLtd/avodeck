# Audit, 19 October 2026

Scope: every slice except O (organisations, not built). Base: `main` at `1a219c1` (after PR #44).
Method: static comparison of every board in `docs/design/screens/` against the built screens; route, endpoint, i18n and pack sweeps; the API and web test suites run against a local Supabase (CLI 2.121, started in this container); targeted rule and scenario checks per slice. Status: **PASS** (matches), **GAP** (missing or different, not broken), **BROKEN** (a user can hit a wrong result, a dead link or a production failure).

The "Fix PR" column names the audit branch that fixes the row. A blank cell means the item is not fixed and is in [Larger items](#larger-items-not-fixed-here) or is a wording-only difference left for the owner.
